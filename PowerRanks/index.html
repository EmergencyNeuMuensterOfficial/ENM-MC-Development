PowerRanks Documentation

A lightweight rank system with a customizable player list for Fabric servers.

Development build. PowerRanks is not currently published as a stable public release.

INSTALLATION

Installation

Once a public build is available, install Fabric Loader and Fabric API for Minecraft 1.20.1, then place the PowerRanks JAR in the server mods folder.

There is no stable download available yet. Do not use unfinished development files on a production server.
