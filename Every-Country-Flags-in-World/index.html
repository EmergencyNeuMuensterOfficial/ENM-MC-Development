FABRIC MOD · 1.20.1

Every Country Flags in World

Place 187 modern and historical flags in your Minecraft world as large decorations with a three-block mast and a two-block flag.

Requires Fabric Loader and Fabric API on Minecraft 1.20.1. Install the same mod version on both client and server.

FEATURES

Features

  • 187 modern and historical flag items, including Kosovo.
  • A dedicated Country Flags creative tab and Flag Selector.
  • Large decorations: a three-block mast and two-block-long flag.
  • Historical flags: Prussia, Austrian Empire, Austria-Hungary and German Empire.
  • Required on both Fabric clients and servers.

INSTALLATION

Installation

  1. Install Fabric Loader for Minecraft 1.20.1.
  2. Install the matching Fabric API version.
  3. Download every-country-flags-fabric-1.0.5+fabric-1.20.1.jar.
  4. Place it in the mods folder on the client and server.
  5. Restart Minecraft or the server.
