NEOFORGE MOD

Every Country Flags in World

Place country flags in your Minecraft world as three-dimensional items and world decorations.

Use the NeoForge build for Minecraft 1.21.1. It is not compatible with Fabric or Paper servers.

FEATURES

Features

  • Country flags as 3D held items.
  • Placeable flag decorations for builds and events.
  • Available on both client and server.

INSTALLATION

Installation

  1. Install NeoForge for Minecraft 1.21.1.
  2. Download the latest mod JAR.
  3. Place it in the mods folder on the client and server.
  4. Restart Minecraft or the server.
